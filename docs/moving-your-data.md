# Moving your data to the new address

Your data lives in your browser, attached to the **address** of the app. When an app moves to
a new address, the browser treats it as a different site, and the new address starts empty.
Your data is still there at the old address: here is how to bring it along.

## Chrono

Chrono moved from `https://wallartn.gitlab.io/chrono/` to the Simple Web Tools site. Chrono is
now available in English and French; the labels below are the English ones, with the French
ones in parentheses. The old GitLab site only speaks French, so there you will see the French
labels.

1. Open the **old** address in the browser you usually use.
2. Click the **Workspace** button (_Espace de sauvegarde_, database icon in the sidebar), then
   **Export JSON** (_Exporter JSON_). Switch to each other workspace you want to keep and export it
   too.
3. Open the **new** address. If you used several workspaces, create the same ones in the
   **Workspaces** dialog (_Espaces de sauvegarde_), under **New workspace** (_Nouvel espace_),
   and switch to each in turn. In each one, open **Workspace**, then **Import JSON**
   (_Importer JSON_) and choose the exported file. Confirm **Replace data** (_Remplacer les
   données_): the workspace was empty, so nothing is lost.
4. Check your projects, sessions and to-dos. Only then clear the old site's data, if you wish.

The import accepts the files exported by the old GitLab version of Chrono as they are (the
oldest format) as well as the exports of the current version.

Do it in every browser and on every device where you used Chrono: each one keeps its own copy.

## Locavern

Nothing to do. Locavern stays on the same site (`numeyoga.github.io`) and only its path
changes, so your data follows.
