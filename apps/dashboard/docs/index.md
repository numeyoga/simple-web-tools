# Dashboard documentation

User documentation for Dashboard, in English. The interface also exists in French; labels are
given in English here.

- [Set up your dashboard](set-up-your-dashboard.md): templates, environments, metadata fields,
  link patterns, tags and applications, and what a link that cannot be opened means.
- [Work with your applications](work-with-your-applications.md): the application screen, edit
  mode, a different address, extra links, the filter and the command menu, workspaces.
- [Back up, restore and move your data](back-up-and-move-your-data.md): the JSON backup, and the
  steps to bring over the data of the earlier version of the dashboard.
- [Interface and shortcuts](interface-and-shortcuts.md): the screen, the shortcuts, the
  preferences.
