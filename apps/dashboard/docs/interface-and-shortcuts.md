# Interface and shortcuts

## The screen

- **Sidebar**: the workspace button, the list of applications with its filter and **New
  application**, the **Administration** screens (Templates, Metadata fields, Tags, Import and
  export, Settings), then the links to the other apps of the suite. Below 1024 px it is a drawer
  opened with the **Menu** button.
- **Top bar**: the name of the dashboard (if you gave it one), the title of the screen, the
  command menu button, **New application** and the **Preferences**.
- **Main region**: one screen at a time. Its address (`#/app/...`, `#/admin/...`) can be
  bookmarked.

## Shortcuts

| Key            | Action                                                    |
| -------------- | --------------------------------------------------------- |
| `N`            | New application. Single-key shortcut, can be turned off.  |
| `/`            | Go to the filter. Single-key shortcut, can be turned off. |
| `Ctrl+K`, `⌘K` | Open the command menu. Always on.                         |
| `Esc`          | Close the open dialog, menu or the sidebar drawer.        |

Single-key shortcuts never fire while you type, when a dialog is open or with a modifier key
(WCAG 2.1.4).

## Preferences

The gear in the top bar. They are yours, kept in this browser, and the same in every workspace.

- **Language**: automatic (the browser's), English or French. Changing it reloads the page.
- **Theme**: system, light or dark.
- **Text size**: automatic (larger on large screens), standard, comfortable or large.
- **Density**: comfortable or compact (tighter rows, more links on the screen).
- **Single-key shortcuts**: on or off.

## Offline

Dashboard works offline once it has been opened: the app is cached and your data is local. The
links themselves lead to your own tools and need their own network.
