# Interface and shortcuts

## The screen

- **Sidebar**: the workspace button, the list of groups (choose one to go to its card) and the
  links to the other apps. Below 1024 px it is a drawer opened by the **Menu** button.
- **Top bar**: the name of the workspace, **New link** and **Preferences**.
- **Toolbar**: the search, **Edit**, **More actions** (new group, export, import, clear all) and
  the number of links.
- **Board**: one card per group, with the number of links, a star, an add button and, in edit mode,
  a handle and a menu.

## Shortcuts

| Key            | Action                                    |
| -------------- | ----------------------------------------- |
| `N`            | New link.                                 |
| `/`            | Search.                                   |
| `Ctrl+K`, `⌘K` | Search.                                   |
| `Esc`          | Close a dialog or a menu, hide a tooltip. |

`N` and `/` can be turned off in the preferences (single-key shortcuts). They never fire while you
type or when a dialog is open.

## Preferences

Language (automatic, English, French), theme (system, light, dark), text size, single-key
shortcuts and the site icons from Google (off by default).
