# Favoris documentation

User documentation for Favoris, in English. The interface also exists in French; labels are given
in English here.

- [Organize your bookmarks](organize-your-bookmarks.md): links, groups, colours, search, reordering
  with the mouse or the keyboard, workspaces.
- [Back up, restore and move your data](back-up-and-move-your-data.md): the JSON backup, the file of
  the earlier version, and what happens to the data of the earlier version on the first start.
- [Site icons and privacy](site-icons-and-privacy.md): what stays on your device, and the one
  optional request to Google.
- [Interface and shortcuts](interface-and-shortcuts.md): the screen, the shortcuts, the preferences.
