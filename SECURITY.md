# Security policy

These apps have no server: data never leaves the browser unless you export it. The main risks
are therefore cross-site scripting through imported files or user content, and leaks through
third-party requests (which the Content Security Policy forbids).

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub security advisories](../../security/advisories/new) rather than in a public issue.
You can expect a first answer within a week.

Only the version currently deployed on GitHub Pages is supported.
